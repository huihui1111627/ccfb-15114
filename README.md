# 赛鸽归巢排序算子 · 编码键执行引擎

把多列排序键（赛区升序、分速降序、归巢时刻升序、鸽舍名按拼音……）一次性编码成
**可直接按字节比较**的字节串，再用 MSD 基数排序整批排完。逐列比较的排序每次比较
都要重算表达式、重比字符串；编码后整键 `bytes.Compare` 就是最终顺序，排序只需要
看字节，而且天然适合并行分桶。

```
go run ./cmd/verify     # 400 组随机列组合/数据 一致性 + 耗时对比
go run ./cmd/sortweb    # 打开 http://localhost:8080 看排序过程
go test ./...           # 单元测试与不变量测试
```

## 需求对照

1. **表达式列**：`distance * 1000 / duration` 这类表达式在编码前对每行求值一次；
   任一操作数为 NULL 结果即 NULL，除零也归为 NULL（零用时的记录与缺失用时同样处理）。
   支持四则运算、比较、三值 AND/OR/NOT、`coalesce/nullif/ifnull/abs/round/floor/ceil`。
2. **每列独立方向与空值位置**：方向与空值位置正交。降序由**值字节按位取反**实现，
   空值位置由列首的一个标记字节决定（NULL 在前 `0x00`/非空 `0x01`，NULL 在后
   `非空 0xfe`/NULL `0xff`）。标记字节不进取反，所以降序不会把 NULL 一起翻转。
3. **变长字符串**：UTF-8 字节中原样输出，`0x00` 写成 `0x00 0x01`，结尾 `0x00 0x00`。
   一个串是另一个串的前缀时顺序仍然正确（`"a" < "a\x00" < "aa"` 与原始字节序一致）。
   所有列自定界，因此任意两行的整键互不为前缀——这是基数排序叶子层可以用输入序号
   作为平局决断的前提。
4. **拼音列**：汉字映射为 `音节*5+声调` 排序码（音节按字母序编号，声调 1..4 打破同音），
   每个字符编码成 2 字节，无读音字符编码成 3 字节且排在所有有读音字符之后。
   字符串按码序列比较即为字典序。码表由 `tools/genpinyin` 从 Unihan 生成，见下。
5. **MSD 基数排序**：每轮按一个字节稳定分桶（计数排序），逐字节下钻；
   桶内 ≤24 行改插入排序。整键等长且自定界，叶子层不需要再读全键。
6. **稳定**：分桶是稳定计数排序、叶子插入排序只在严格大于时移动、堆比较带输入序号
   兜底，因此键相同的行保持输入顺序。
7. **Top-K**：`TopK` 用最大堆维护前 k 个，堆顶比较同样用编码后的键（键相同再比输入
   序号），选出后再排一次，结果与全排序截断完全相同。
8. **并行分桶**：先按首字节（必要时继续下钻）把行稳定分成按字节序排列的叶子区间，
   各 worker 独立排序，排完各叶子的位置本来就相邻且有序，**直接拼接即最终结果，
   没有归并步骤**。字符串/拼音列的桶号天然对应值域范围。

## 编码格式一览

| 列类型 | 值字节（升序） | 说明 |
| --- | --- | --- |
| int | `uint64(v) ^ 1<<63`，8 字节大端 | 负数在前，可直接比较 |
| uint | 8 字节大端 | |
| float | IEEE-754 保序映射，8 字节大端 | `-0` 归一为 `+0`；NaN 统一位型并排在 `+Inf` 之后 |
| bool | `0x00` / `0x01` | |
| string | 转义后的 UTF-8 + `00 00` | 前缀安全 |
| string（拼音） | 每字符 2/3 字节码 + `00 00 00` | 音节、声调、无读音分层 |
| any（混合类型） | 类型标签 + 上面的值字节 | 标签序 bool<int<uint<float<string |
| 降序 | 仅把**值字节**按位取反 | 空值标记不受影响 |

列首空值标记：`NULLS FIRST` 为 NULL→`0x00`、非空→`0x01`；`NULLS LAST` 为
非空→`0xfe`、NULL→`0xff`。

## 拼音码表

`sortengine/pinyin_table.gen.go` 由 `tools/genpinyin`（Python，仅开发时运行）从
Unicode 18.0.0 的 `Unihan_Readings.txt` 中 44,355 条 `kMandarin` 读音生成：

- 418 个无调音节按字母序编号，码为 `音节*5+声调`（1–4，轻声为 0）；
- U+3400–U+9FFF 用稠密数组，其余 17,644 个码位用二分查找；
- 多音字取 Unihan 的首选读音；
- 无读音字符按码位排在所有有读音字符之后，保证全序且稳定。

重新生成：`python3 tools/genpinyin/gen.py Unihan_Readings.txt 18.0.0 sortengine/pinyin_table.gen.go`。

## 验证

`go run ./cmd/verify` 默认跑 400 组随机用例，每组随机 1–5 个排序列，随机方向与
空值位置，随机表达式；数据中混入约 1/8 的空值、`-0`、NaN、±Inf、前缀关系字符串
（含内嵌 NUL）、大量重复键。每组检查：

- 与 `sort.SliceStable` 逐列比较（参考实现）的结果**逐位相同**；
- `TopK = 1/3/25` 与全排序前 k 行**逐位相同**；
- 关闭并行的串行路径与并行路径结果相同；
- 最后打印编码键排序与逐列比较排序的耗时对比。

## 已知边界

- `any`（混合类型）列在升序下语义完整；降序会把类型标签一并取反，适合同类型数据，
  混合类型 + 降序时各类型内部仍有序，但类型之间的先后会被翻转。
- 浮点与跨类型数值比较在参考实现中按精确数学值比较；编码器按 IEEE-754 保序映射，
  两者对 double 能表示的任意值一致（`-0 == +0`、`NaN` 统一为最大）。
